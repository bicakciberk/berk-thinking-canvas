My name is Berk Bıçakçı.

* intelligent
* calm

# TYPOGRAPHY

Typography is one of the main design elements.

Use a sophisticated serif for:

* hero headline
* major section headings
* important numbers

Use a clean sans-serif for:

* body
* navigation
* metadata
* buttons

Make body text comfortably readable.

Do NOT make body text tiny just to achieve an editorial look.

Desktop body text should generally be around 15–17px.

Mobile body text should generally be around 15–16px.

Use generous but not excessive line-height.

# ANIMATIONS

Use GSAP carefully.

Only animate:

* hero entrance
* subtle text reveal
* section reveal
* small hover interactions
* subtle movement in hero visual

Do NOT animate everything.

Avoid:

* excessive parallax
* constant floating
* animated gradients
* aggressive scroll effects
* cursor-following effects

Disable cursor-specific effects on touch devices.

Respect prefers-reduced-motion.

Animations should feel almost invisible.
